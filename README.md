# MAD DOGS OF CUMBICA'S WORLD

RPG 2D top-down em pixel art (HTML5 Canvas + JavaScript puro, sem dependências externas), inspirado na exploração e nas batalhas por turnos de Pokémon FireRed. Ambientado em uma versão estilizada de **Cumbica, Guarulhos – SP**. Protagonista: **Gabe**.

> Os ginásios e personagens são adaptações fictícias para o jogo; não representam estabelecimentos reais funcionando como arenas.
